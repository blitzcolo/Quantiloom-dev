  三、开题报告框架

  1. 研究目的

  传统红外图像仿真软件（如 DIRSIG、CAMEO-SIM）存在以下问题：
  1. 闭源或出口管制，国内难以使用
  2. 基于 CPU 的光线追踪，效率低下
  3. 光谱渲染与传感器效应分离，无法端到端优化

  本研究基于 Vulkan Ray Tracing 构建统一的高光谱红外成像仿真系统，
  实现从场景辐射计算到传感器响应的全链路物理建模。

  2. 研究内容（六大模块）

  模块一：光谱路径追踪核心 (已完成，展示)
     ├─ Vulkan RT 加速结构管理
     ├─ Cook-Torrance PBR + 物理 Fresnel
     └─ 波长依赖的 BRDF 评估

  模块二：多波段联合渲染 (重点开发)
     ├─ Hero Wavelength Sampling
     ├─ MIS 权重计算
     └─ HDF5 数据立方体输出

  模块三：红外辐射传输模型 (已有基础，增强)
     ├─ Planck 黑体辐射
     ├─ Beer-Lambert 大气衰减
     └─ MODTRAN LUT 集成

  模块四：传感器效应建模 (新增开发)
     ├─ 光学模块：PSF 卷积（MTF）
     ├─ 探测器模块：光电转换 + 泊松噪声
     ├─ 固定图案噪声：PRNU/DSNU
     └─ NUC 残差模拟

  模块五：多波段融合显示 (新增开发)
     ├─ VIS/SWIR/MWIR 三波段融合
     ├─ 基于 Laplacian 金字塔的多尺度融合算法
     ├─ 动态范围自适应归一化
     └─ 灰度/伪彩色双模式输出

  模块六：验证与评估 (新增开发)
     ├─ 与 PBRT-v4 渲染结果对比
     ├─ NETD 指标验证
     ├─ MTF 测量验证
     └─ 多波段融合效果评估

  3. 创新点提炼

  创新点1：GPU 加速的全光谱路径追踪
     - 基于 Vulkan Ray Tracing 实现 380-12000nm 全波段支持
     - 相比 CPU 渲染器提升 10-100x 效率

  创新点2：物理一致的传感器效应建模
     - 从第一性原理建立辐射-光电子-信号链
     - 模块化可配置（TOML），支持多种探测器型号

  创新点3：端到端的高光谱数据立方体生成
     - 场景→辐射→传感器→DN，全链路可追溯
     - 填补国内开源红外仿真工具空白

  创新点4：面向目标探测的多波段融合显示
     - 提出基于 Laplacian 金字塔的 VIS/SWIR/MWIR 三波段融合算法
     - 实现动态范围自适应归一化，解决各波段量纲差异问题
     - 增强伪装目标在融合图像中的可见性，支持定性分析

  七、多波段融合模块详细设计

  7.1 功能定位

  该模块用于将 VIS（可见光）、SWIR（短波红外）、MWIR（中波红外）三个波段的
  渲染结果进行融合，生成一张增强显示的灰度图。

  应用场景：
  - 某些伪装涂层的物体在可见光图片里与周围物体难以区分
  - 但在红外热成像图里能清晰识别
  - 融合图将各波段的高响应区域叠加，增强目标可见性

  输出说明：
  - 输出格式：OpenEXR（HDR）+ PNG（LDR 预览）
  - 用途定位：定性分析/目标探测，非定量研究
  - 物理量纲：融合后已无具体物理单位，仅作视觉增强

  7.3 融合算法对比

  | 算法              | 复杂度 | 效果   | 工作量  | 说明                      |
  |-------------------|--------|--------|---------|---------------------------|
  | 简单加权平均      | ⭐     | ⭐⭐   | 100 行  | `Fused = w1*VIS + w2*SWIR + w3*MWIR` |
  | Laplacian 金字塔  | ⭐⭐⭐ | ⭐⭐⭐⭐| 400 行  | 多尺度融合，保留边缘细节（推荐） |
  | 最大响应选择      | ⭐⭐   | ⭐⭐⭐ | 150 行  | 逐像素选最大值            |
  | 伪彩色映射        | ⭐⭐   | ⭐⭐⭐ | 200 行  | VIS→R, SWIR→G, MWIR→B     |

  推荐组合：Laplacian 金字塔（主）+ 伪彩色（辅）

  7.4 Laplacian 金字塔融合算法

  算法原理：
  1. 对 VIS/SWIR/MWIR 各构建 N 层 Laplacian 金字塔
  2. 在每一层，选择绝对值最大的系数（保留边缘）
  3. 从顶层重建融合图像

  伪代码：
  ```
  function LaplacianFusion(vis, swir, mwir, levels):
      // 1. Build Laplacian pyramids
      L_vis  = BuildLaplacianPyramid(vis, levels)
      L_swir = BuildLaplacianPyramid(swir, levels)
      L_mwir = BuildLaplacianPyramid(mwir, levels)

      // 2. Fuse at each level (max absolute value)
      L_fused = []
      for i in 0..levels:
          L_fused[i] = MaxAbs(L_vis[i], L_swir[i], L_mwir[i])

      // 3. Collapse pyramid to get fused image
      return CollapseLaplacianPyramid(L_fused)
  ```

  优点：
  - 保留各波段的高频细节（边缘、纹理）
  - 自动适应各波段的动态范围
  - 经典方法，论文引用多，易于答辩解释

  7.5 TOML 配置示例

  ```toml
  [multiband_fusion]
  enabled = true
  method = "laplacian_pyramid"  # weighted_average | laplacian_pyramid | max_response | pseudo_color
  pyramid_levels = 5

  [multiband_fusion.weights]
  vis = 0.4
  swir = 0.3
  mwir = 0.3

  [multiband_fusion.normalization]
  auto_normalize = true
  vis_min = 0.0
  vis_max = 1.0
  swir_min = 0.0
  swir_max = 1e-3
  mwir_min = 0.0
  mwir_max = 1e-2

  [multiband_fusion.output]
  exr_path = "output/fused_vis_swir_mwir.exr"
  png_path = "output/fused_vis_swir_mwir.png"
  ```

  1. **定位清晰**：该模块是"功能完善"而非"核心创新"，不宜过度包装
